# Support

## Questions and usage help

- Use GitHub Discussions if it is enabled.
- If it is not enabled, open a GitHub issue for bug reports or feature requests.

## Before opening an issue

Include these items in the issue:

- operating system and architecture
- ClickHouse version
- how the project was started
- relevant environment variables
- logs, screenshots, or reproduction steps

## Security issues

Do not use public issues for security reports. Read `SECURITY.md`.
