Put any number of versioned chdash release archives here.

Accepted extensions:

- .tar.gz
- .tgz
- .tar
- .zip

The release container automatically selects the highest semantic-looking version in the filename, for example:

- chdash_2.8.1_linux_amd64.tar.gz
- chdash_2.8.2_linux_amd64.tar.gz
- chdash_2.10.0_linux_amd64.tar.gz

In that example, 2.10.0 is selected.

Keep the original versioned names.
