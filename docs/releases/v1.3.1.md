# v1.3.1 — The macOS build of 1.3.0

Base: the code of 1.3.0. The build of 1.3.0 for macOS failed, so 1.3.0 has no release. Version 1.3.1 is the first release of this code. Read `v1.3.0.md` for the changes: ChDash is now a service of ProcurAuth.

## What changes

- The transport of the PDP (`src/pdp_transport.cpp`) opened its sockets with `SOCK_CLOEXEC`, `SOCK_NONBLOCK` and `MSG_NOSIGNAL`. macOS has none of these. The transport now sets the flags with `fcntl` and the option `SO_NOSIGPIPE` where the first flags do not exist. The Linux code path does not change.

## Upgrade

- The upgrade from 1.2.2 is the one that `v1.3.0.md` describes. Change `portal.actions` in the same deployment.

## Validation

- The native tests, the harness, the TLS test of the PDP (`tests/tls/pdp.sh`) and the ProcurAuth conformance run give the results that `v1.3.0.md` lists. The Linux build uses the same source.

## Downloads

- Linux and macOS archives, `SHA256SUMS` and the build provenance attestation are in the release `v1.3.1`.
