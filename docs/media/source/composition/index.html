This is ClickHouse Dash:

real-time dashboard for ClickHouse.
Write a query,
and format it.
Run it, and watch the numbers fill in live.
Switch to a chart,
and explore it right there.
Keep the good ones.
Name it, file it in a folder,
and the whole team can open it.
The Explorer sizes every database,
opens any table down to its parts and its DDL,
and draws the lineage.
